# ORBIT HOP (궤도 점프)

행성 궤도를 빙글빙글 돌다가 **탭 한 번**으로 날아가는 원탭 픽셀 우주 게임이에요.
다음 행성의 점선 궤도에 닿으면 붙잡히고, 그렇게 계속 위로 올라가면 돼요.

**플레이: https://lhc6835-hue.github.io/one/**

## 규칙

| | |
|---|---|
| 조작 | 화면 탭 · 클릭 · 스페이스(아무 키) |
| 비행 | 탭하면 접선 방향으로 튀어 나가 **행성 쪽(안쪽)으로 휘었다가** 점점 곧게 펴져요. 조준선이 그 곡선을 그대로 보여줘요 |
| 포획 | 다음 행성의 점선 궤도 안으로 들어가면 붙잡혀요. 들어온 방향대로 돌아요 |
| PERFECT | 궤도 **가장자리를 스치듯** 들어가면 PERFECT. 3연속마다 점수 배율 +1 |
| 건너뛰기 | 한 번에 행성 여러 개를 건너뛰어 더 위 행성에 잡히면, 사이에 있던 행성도 점수로 쳐요(행성 점수 × 배율 + 1씩). 건너뛴 행성마다 빛줄기가 혜성으로 꽂히고 "xN SKIP" 연출이 터져요. 방패 구조 비행은 제외 |
| 공허 | 아래에서 붉은 공허가 올라와요. 머뭇거리면 삼켜져요 |
| 용암 행성 | 붙잡히고 한 바퀴 남짓 지나면 터져요 |
| 블랙홀 | 근처를 지나면 경로가 휘어요. 아슬아슬하게 스치면 CLOSE! +2 |
| 소행성 | 비행 중에 부딪히면 끝 |
| 금빛 방패 | 공허 · 블랙홀 · 화면 이탈 · 행성 폭발 · 소행성, **어떤 죽음이든** 한 번 막아 줘요. 깨지는 순간 가장 가까운 안전한 행성으로 자동 유도 비행해요(블랙홀은 함께 붕괴) |
| 부활 | 게임오버 화면에서 6초 안에 코인을 내면 같은 판을 이어 가요. 한 판에 최대 3번, 30 → 60 → 120 코인. 가까운 안전한 행성에서 금빛 방패를 두르고 다시 시작해요 (키보드는 R) |
| 항성 | 3점. 대신 빨리 돌아요 |
| 코인 | 모아서 혜성 12종을 열어요. **혜성마다 비행 궤도가 달라요** |

점수에 따라 구역이 바뀌어요. 저궤도 → 성운(15) → 소행성대(35) → 심우주(60) → 특이점(100).
구역마다 하늘 색과 성운이 달라지고, 심우주에서는 오로라가 떠요.

## 전체화면 · 설치

- 처음 화면을 탭하는 순간 자동으로 전체화면이 되고, 폰에서는 세로로 고정돼요. 뒤로가기 등으로 풀려도 다음 탭에 다시 전체화면이 돼요.
  브라우저는 사용자 입력 없이 전체화면을 허락하지 않아서, 첫 탭 때 켜는 방식이에요.
- 아이폰 사파리는 웹페이지 전체화면을 지원하지 않아요. 대신 공유 → **홈 화면에 추가**로 설치하면 주소창 없이 전체화면 앱으로 열려요(`manifest.webmanifest`, 픽셀 아이콘 포함). 안드로이드도 설치할 수 있어요.

## 혜성 12종

| 혜성 | 가격 | 궤도 |
|---|---|---|
| 혜성 | 기본 | 안쪽 곡선: 행성 쪽으로 부드럽게 |
| 불씨 | 30 | 직진: 곧게, 조금 빠르게 |
| 네온 | 60 | 바깥 곡선 |
| 오로라 | 100 | 큰 호: 길고 완만하게 |
| 서리 | 140 | 느린 곡선 |
| 독침 | 180 | 갈고리: 발사 직후 확 꺾임 |
| 유령 | 220 | 바깥 호 |
| 물뱀 | 260 | 뱀: 구불구불 |
| 황금 | 320 | S자 |
| 태양풍 | 380 | 급행: 아주 빠르게 |
| 심연 | 450 | 공전: 끝없이 휘어 돎 |
| 프리즘 | 550 | 지그재그 |

궤도는 `src/game/world.js`의 `FLIGHTS`에 있어요. 진행 방향이 도는 속도를
`side · (w0·e^(-t/tau) + amp·sin(2π·freq·t + phase)·e^(-t/wtau))`로 정해요.
상점 카드의 미리보기도 게임과 같은 계산으로 그려요.
레벨 생성기는 **지금 고른 혜성의 궤도로** 점프 가능 여부를 검증하기 때문에, 혜성을 바꾸면 맵도 새로 만들어요.
12종 각각을 봇으로 검증했어요. 정확한 봇 144판 중 141판이 150점까지 갔어요.

## 공정성: 모든 점프는 실제로 가능해요

행성을 놓을 때마다 **지금 궤도에서 발사해 다음 행성에 잡히는 발사 각도 구간**을 계산해요.
곡선 비행과 블랙홀 중력까지 실제 물리와 같은 함수(`advance`), 같은 간격(1/240초)으로 계산하고, 그 구간이 일정 시간(처음엔 0.42초, 점점 줄어서 최소 0.12초)
이상 확보될 때만 배치해요.

`tools/bot.mjs` 봇으로 검증했어요. 봇은 블랙홀, 움직이는 행성, 소행성까지 넣어 "지금 쏘면 어디에 잡히는지"를
예측하고 발사 구간의 가운데를 노려요.

```
npm run bot          # 60판, 반응 지연 0.15초, 타이밍 오차 50ms
node tools/bot.mjs 40 0.15 0      # 오차 없음: 40판 모두 400점 도달 (막히는 맵 없음)
node tools/bot.mjs 40 0.15 0.04   # 잘하는 사람 수준: 중앙값 약 100점
node tools/bot.mjs 40 0.15 0.07   # 초보 수준: 중앙값 약 32점, 하위 10%도 9점
```

## 실행

```bash
npm install
npm run build      # dist/index.html 한 파일로 빌드
npm run dev        # http://localhost:5173
```

GitHub Pages 배포는 빌드한 `dist/` 안의 `index.html`, `manifest.webmanifest`, `icons/`, `music/`을 `gh-pages` 브랜치에 올리면 돼요.

## 연출

화면은 짧은 변이 약 260px인 픽셀 프레임에 그리고 정수배로 키워요.
그 위에 빛 버퍼만 흐리게 만들어 더하는 블룸, 스캔라인, 비네트를 얹었어요.

- **행성:** 종류별 경도·위도 텍스처(64×32)를 만들어 두고, 구 위 픽셀마다 텍스처를 읽어 자전시켜요.
  왼쪽 위에서 오는 빛으로 명암을 넣고, 경계는 Bayer 디더로 처리해요.
  암석(사막·바다·라일락), 얼음, 고리 달린 가스 행성, 갈라진 틈이 빛나는 용암 행성, 위성, 항성이 있어요.
- **배경:** 세 겹 시차 별밭, 구역 색을 따라가는 성운, 심우주 오로라.
- **pixelfx 이펙트:** `pickups/collect-burst`, `impacts/crit-hit`, `impacts/parry`, `ui/combo-counter`,
  `explosions/firework-burst`, `explosions/plasma-explosion`, `arcane/mana-burst`, `lightning/zap-hit`,
  `ui/confetti`, `holy/sunburst`(항성), `weather/aurora`, `weather/shooting-stars`(타이틀)
- **게임 전용 이펙트:** `src/game/fx-custom.js`. 판정 글자, 궤도 물결, 별가루, 구역 배너를
  pixelfx 규약으로 만들었어요.
- **손맛:** PERFECT 때 0.045초 히트스톱, 화면 흔들림, 섬광, 죽을 때 슬로모션.
- **효과음:** WebAudio로 즉석 합성해요. 포획음이 콤보를 따라 5음계로 올라가요.
- **배경음:** [Lights at Night](https://opengameart.org/content/lights-at-night)(Tsorthan Grove, CC0) 한 곡을 처음부터 끝까지 반복해요.
  [ye](https://github.com/lhc6835-hue/ye) 프로젝트에서 쓰던 파일을 가져왔어요. 곡 끝 5초가 페이드아웃이라 처음과 겹쳐 이음새 없는 루프로 만들고,
  음량을 -18 LUFS로 맞췄어요(`public/music/bgm.ogg`, 사파리용 `bgm.mp3`). 게임오버와 일시정지 때는 먹먹해져요.
  곡을 못 불러오면(예: `dist/index.html`을 `file://`로 열었을 때) 실시간 합성 우주 앰비언스가 대신 깔려요.

## 구조

```
src/game/world.js       규칙·물리·레벨 생성 (DOM 없음, Node 에서 봇으로 돌아감)
src/game/view.js        렌더링, 카메라, 이벤트 → 이펙트·소리
src/game/planets.js     행성·소행성 픽셀 렌더러
src/game/sfx.js         효과음·배경음 합성
src/game/skins.js       혜성 스킨
src/game/fx-custom.js   게임 전용 pixelfx 이펙트
src/main.js             화면 흐름, 입력, 저장(최고 기록·코인·스킨)
src/vendor/pixelfx/     pixelfx 코어와 사용한 이펙트 (MIT)
tools/build.mjs         단일 HTML 빌드
tools/bot.mjs           공정성·난이도 검증 봇
```
